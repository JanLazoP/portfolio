CASO DE ESTUDIO

Desarrollo de una API REST con Sequelize

Este proyecto representa una de los principales desafíos técnicos desarrollados durante el curso y refleja la evolución de mis conocimientos adquiridos en backend y bases de datos.

01. Descripción

Durante el desarrollo del proyecto trabajé en la construcción de una API REST utilizando Node.js y Express, conectada a una base de datos PostgreSQL mediante Sequelize.

En la etapa final se incorporó autenticación mediante JWT.

02. Desafío principal

El principal desafío fue integrar los diferentes conocimientos adquiridos durante el curso en una aplicación backend funcional. La definición correcta de los modelos fue una de las tareas que más tiempo me tomó, principalmente debido a las validaciones necesarias antes de enviar los valores a la base de datos, ya que algunos errores en estas validaciones podían generar problemas al momento de guardar la información.

Otro aspecto que presento un desafío fue el manejo de las APIs y la organización de la aplicación. La modularización de controladores, modelos, validaciones, middlewares y rutas tomó bastante tiempo y concentración, ya que era necesario comprender cómo se relacionaba cada componente para lograr que todas las partes funcionaran en conjunto.

03. Solución propuesta

Para solucionar este desafío se implementaron modelos utilizando Sequelize y se definieron relaciones mediante asociaciones como hasMany y belongsTo.

Se validó mediante middlewares que los datos sean del tipo correcto antes de ser enviados para no tener problemas con la base de datos.

04. Herramientas técnicas

Se utilizaron herramientas como, Node.js, Express, PostgreSQL, Sequelize, JavaScript, JWT, Multer, Git y Github.

05. Principales aprendizajes

Los principales aprendizajes que puedo rescatar del proyecto son como manejar modelos de las entidades de la base de datos mediante Sequelize y sus relaciones. Esto me ayudo a como trabajar con PostgreSQL desde Node.js

El otro aprendizaje que agregaría es el desarrollo de las APIs REST, esto fue un trabajo muy grande pero me ayudo comprender mejor a modularizar mi código, como manejar rutas, controladores y middlewares de mi proyecto y finalmente a trabajar con autenticación mediante JWT.

06. Métricas de impacto

Este proyecto logra incorporar 4 modelos principales, el manejo de relaciones entre las entidades utilizando Sequelize, operaciones CRUD cada una con su archivo dedicado por entidad, autenticación mediante JWT para proteger determinadas operaciones, validaciones para cada entidad como middlewares y carga de archivos utilizando Multer para gestionarlos.

El proyecto me permitió integrar conocimientos que fueron trabajados incialmente de manera independiente, como Node.js, Express, PostgreSQL, APIs REST y JavaScript. Estos posteriormente fueron combinados para desarrollar una aplicación backend completa.
